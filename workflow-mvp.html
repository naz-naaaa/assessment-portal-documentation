Assessment Portal — MVP Workflow

Phase 1 (MVP) end-to-end mechanism, per requirements.md and tech-stack.md.

Scope: this diagram shows what actually ships in Phase 1 — MCQ / single-choice / short-answer / file-upload / free-text question types, manual + PDF-assisted authoring, manual assignment, autograding + manual review, and reporting. It deliberately omits Phase 2 items (SSO, sandboxed code-exercise autograding, email notifications, deeper analytics) — see the table at the bottom.

1. End-to-end lifecycle

primary flow status / visibility update
  1. Provision & configure — Super Admin adds the new hire (manual or CSV) and, separately, sets the Mistral API key used for PDF question import. FR-3, FR-33
  2. Author assessment — Admin builds questions manually or uploads a PDF (parsed via Mistral AI, always reviewed in an editable preview before save). FR-5, FR-6
  3. Assign to track — Assessment is attached to a role/department onboarding track template. FR-8, FR-11
  4. Candidate takes it — Dashboard → start → autosave → resume or auto-submit on timeout. FR-16–FR-19
  5. Submit → split grading — Objective answers (MCQ/single-choice) auto-score immediately; free-text/file answers land in the Reviewer's queue. FR-22, FR-24
  6. Score & status — Overall score and pass/fail computed once both grading paths complete; track status updates; candidate sees results. FR-20, FR-25
  7. Onboarding-complete check — Once all required assessments are passed and/or reviewer sign-off is recorded. FR-15
  8. Reporting — Admin views the funnel/per-hire/per-assessment reports, exports CSV/PDF, and reviews the audit log. FR-27–FR-30, FR-34
